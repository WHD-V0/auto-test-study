完整工作流参考；已有同等内容时无需重复新建。只用于你自己的仓库。

```yaml
name: API regression
on:
  push:
  pull_request:
permissions:
  contents: read
jobs:
  regression:
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest]
    runs-on: ${{ matrix.os }}
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: pip
      - name: Install dependencies
        run: python -m pip install -r requirements.txt
      - name: Record installed versions
        shell: bash
        run: |
          mkdir -p reports
          python -m pip freeze > reports/installed-requirements.txt
      - name: Validate and run Linux regression script
        if: runner.os == 'Linux'
        env:
          PYTHON_BIN: python
        run: |
          bash -n scripts/run_regression.sh
          bash scripts/run_regression.sh
      - name: Run Windows local regression in two workers
        if: runner.os == 'Windows'
        run: python -m pytest -n 2 --html=reports/report.html --self-contained-html --junitxml=reports/junit.xml
      - name: Upload results even when tests fail
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: regression-${{ matrix.os }}
          path: reports/
          if-no-files-found: warn
          retention-days: 7
```

**当天写完后的参考代码：**

git archive只打包HEAD已提交内容，因此先提交你要交付的个人成果。使用新目录与新venv，避免旧环境掩盖依赖缺失；脚本不会删除旧目录，重做需改目录名。

文件 `exercises/ci/day07_clean_room.ps1` — 新建此文件；已存在时对照合并，以下是本日完整版本。 [打开参考文件](reference/07/day07/exercises/ci/day07_clean_room.ps1)

```powershell
$ErrorActionPreference = 'Stop'
$lessonRoot = (Get-Location).Path
$lessonDest = Join-Path $lessonRoot 'reports/learning/clean-room'
$lessonZip = Join-Path $lessonRoot 'reports/learning/clean-room.zip'
if (Test-Path $lessonDest) { throw 'clean-room已存在，换新目录名；不要覆盖已有成果' }
New-Item -ItemType Directory -Force (Split-Path $lessonZip) | Out-Null
git archive --format=zip --output=$lessonZip HEAD
if ($LASTEXITCODE -ne 0) { throw 'git archive失败' }
Expand-Archive -LiteralPath $lessonZip -DestinationPath $lessonDest
& .\.venv\Scripts\python.exe -m venv "$lessonDest/.venv"
if ($LASTEXITCODE -ne 0) { throw '干净环境创建失败' }
$lessonPython = Join-Path $lessonDest '.venv/Scripts/python.exe'
Push-Location $lessonDest
try {
    & $lessonPython -m pip install -r requirements.txt
    if ($LASTEXITCODE -ne 0) { throw '干净环境安装失败' }
    & $lessonPython -m pytest
    if ($LASTEXITCODE -ne 0) { throw '干净环境回归失败' }
} finally {
    Pop-Location
}
Write-Output 'HEAD提交的干净环境可复现；未提交改动不在此副本中。'
```
